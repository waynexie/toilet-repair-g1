# 开局流程 v2（策划草案，2026-11-10）

目标：**进游戏 5 秒内上手操作，约 40 秒拿到第一笔钱，约 60 秒接到第一个电话**，玩家还没来得及想"这游戏玩什么"，就已经在干活了。
结构上借鉴《沙威玛传奇》开局（客户站在面前提需求 → 一步一手指 → 第一单马上结算 → 立刻来下一单，难度加一点），内容全部按自己的来。

## 一、去掉的和保留的
- 第 1 天去掉开场的「早上在家 / 妈妈提醒吃早饭」，首次启动也不显示首页，直接进王阿姨家厕所。
- 建议：第 2 天起保留早上的过场（一句妈妈的喂信预览，点任意处跳过），它是"上班一天"的节奏点。**这一条请 Grok Bot 跟 Wen 确认**。
- 第 2 次及以后启动时显示首页「开工」。

## 二、逐步流程（第 1 单 o1 → 第 2 单 o2 接起）

## 三、前 60 秒的爽点分布
1. 0–5s：第一下就能点（冲水），立刻有反应（水涨 + 王阿姨惊叫）。
2. 约 30s：咕噜通了，第一次"修好了"的手感奖励，屏幕震 + 音效。
3. 约 40s：第一笔钱飞进胶囊。
4. 约 50s：电话响，有人急着找你，"我被需要了"。
5. 约 2.5min：o2 做完，**第一次打赏**放在这里——徐哥「不用找了」硬塞 ¥5（已在 economy.json 的 scripted 里）。第一单不打赏，留给急活结束，正好接住紧张感。

## 四、头像对话气泡规则（给 UI、开发、叙事）
- 从客户卡右侧弹出，尖角指向头像；同一时间只有一个气泡，显示 2.4s，两条之间至少隔 3s。
- 触发事件与情绪（台词键由叙事填，每类 2–3 句随机）：

| 事件 | 情绪 | 表情 |
|---|---|---|
| 订单开始 | 需求 | 随当前档 |
| 掉第 1 格耐心 | 寒暄/轻催 | p2 |
| 掉第 2 格 | 催促 | p3 |
| 剩最后 1 格 | 着急 | p4 |
| 拿错工具 | 疑惑 | 当前档 |
| 8s 没操作 | 催促（不重复老钱提示） | 当前档 |
| 疏通成功 | 感谢 | p1 |

- 操作引导提示出现时，客户气泡让位，避免两个字条同时出现。

## 五、跳过与重复
- 全部引导只在首次出现，存 `tutorialDone`；设置里加「重新看新手引导」。
- 回流玩家（已完成 o1）启动后不再出 S1–S9 的引导遮罩，只保留气泡。

## 六、参考《沙威玛传奇》拆解后的修订（22:55）
1. **引导改轻**：冲水和拖工具不一上来就压遮罩，先让王阿姨用台词提示；玩家 3 秒没动出手指，6 秒还没动才压遮罩。只有节奏圈第一次出现时保留明确的教学提示。
2. **钱要玩家自己点**：工钱落在马桶盖上，点一下金币飞进胶囊；4 秒没点就自动收，钱不会丢。手动收钱比自动加数更有实感。
3. **提前看到想要的东西**：专业皮搋子从第一单起就灰着放在工具箱里，标「¥100 解锁」，玩家第一天就有攒钱目标，当天收入 ¥208 正好够买。
