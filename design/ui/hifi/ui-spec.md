# UI 规范 v1（按 art-spec v2 / gameplay_frame_v1，2026-11-10）
效果图：`hifi_v1_artv2.png`（源文件 `hifi_v1.html`）。v0（`hifi.html` / `hifi_v1.png`）作废。
效果图背景用的是样张，抹掉了原来画进去的头像和金币，正式版背景里本来就不画 UI。

## 画布
- 逻辑画布 390×780。背景按 375×812 出图，等比铺满，上下各裁掉约 15px。上下这 15px 不放可点的东西。
- 右上角 0–44 留给微信 / 抖音小游戏的胶囊菜单，HUD 从 top 48 开始。

## 通用（v2 画风）
- 描边：暖棕 #5A4030，2px；卡片里的分隔线用 1.5px 虚线 #E0CFB2。不再用 3px 黑描边和硬投影。
- 投影：`0 3px 8px rgba(70,45,25,.28)`。按钮另加内阴影 `inset 0 -4px 0 rgba(90,64,48,.22)`；按下时下移 2px，去掉内阴影。
- 卡片底色 #FFF8EC；圆角：卡片 20、按钮 14、胶囊 20。
- 主按钮用金色渐变 #FFD45E→#F5B92E，高 58，字号 20、粗体。次按钮白底，高 44，字号 15。
- 最小字号 12，点击区域至少 44×44。遮罩 rgba(43,30,20,.55)，弹出时游戏暂停。
- 功能色不变：金币 #FFC83D，有效 #6FCF6F，无效 #F07A5C，红点 #D9413A。

## ① 维修中 HUD（左右分开）
- 左上客户卡：left 12 / top 48，宽 74。头像 60×60，圆角 10；下面 4 个耐心点，直径 10。掉一格时头像抖一下，换一张表情。
- 右上金币胶囊：right 12 / top 48，高 40；¥ 金币 28，数字字号 20、粗体。
- 金币胶囊下方：左边是「本单 ¥30 +小费」小牌（高 36），右边是 ⚙（44 圆形，top 92）。这块墙面美术已经留空。
- 台词气泡：头像右侧，left 96 / top 150，最大宽 220，尖角指向头像，3 秒后淡出。冲水按钮在 y≈240，两者不冲突。
- 反馈字「完美!」#6FCF6F，字号 32，1.5px 棕色描边。

## 工具箱托盘
- 箱体 290×130，left 12 / bottom 18，下面铺一条地砖底（高 190，把背景里原来的托盘位置盖住）。素材来自 art-spec v2 的分层图：箱盖、箱体、隔板、挂锁挡板。
- 4 格，每格点击区域 64×84（含格子上方的工具伸出部分）。工具名字号 12、粗体、浅色，写在箱体正面、每格的正下方。
- 选中的格子：工具上抬 8px，外面加一圈 3px #FFE27A 发光描边。锁住的格子写「升级解锁」，点一下挂锁晃一晃，再弹「去五金店看看」。
- 升级换皮：只换箱盖和箱体两层，格子的位置和点击区域不变。

## 旧手机和老钱按钮
- 手机平放在地上，在工具箱右侧：right 14 / bottom 34，62×94，转 −10°。红点 20，显示未读数。
- 结算、升级、设置这几个弹层打开时，手机放在遮罩上面，只显示红点 +1，不弹通知条。
- 📞 问老钱：52 圆形，在手机正上方（right 20 / top 560）。平时半透明，触发后亮起，外圈加一道金色光晕，晃一下。角标第一次写「今日免费」，之后写「▶广告」，这一单用过就隐藏。触发条件不变。

## ② 结算页 / ③ 升级卡 / ④ ⚙ 设置卡
- 内容和顺序同 v0，只换成 v2 的描边和投影。结算页用客户头像图（84，圆角 18），压在卡片顶边上。
- 结算对比条：#E8F7E4 底，1.5px #9CCB92 描边，深绿字。
- 升级卡：余额不足时，主按钮变灰，写“还差 ¥X”。
- 设置卡：省动效的图标改成 ✨，不再用乌龟。
